**Space Shooter Game**



A 2D Android Space Shooter game developed using Java and Android Studio.

The player controls a spaceship, shoots enemies, survives levels, and scores points.





**About the App**



Space Shooter is an action-based mobile game where the player fights against enemy spaceships.

The game includes multiple levels, enemy shooting, player lives system, and increasing difficulty.



This project is developed for educational purposes to demonstrate Android game development skills.

**Features**



**-** Start screen with loading system

\- Player spaceship control (touch movement)

\- Shooting system (player bullets)

\- Enemy AI with random shooting

\- Multiple levels (increasing difficulty)

\- Lives system (hearts)

\- Score tracking system

\- Game Over screen with restart option



**Technologies Used**



\- Java (Android)

\- Android Studio

\- XML Layouts

\- Canvas 2D Game Engine

\- Bitmap Images (Sprites)
